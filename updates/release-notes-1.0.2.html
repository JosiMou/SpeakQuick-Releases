v1.0.2

Improvements

  • Improved upgrade completion so SpeakQuick keeps checking for a confirmed unlock after checkout instead of giving up too quickly.
  • Added clearer recovery messaging when access cannot be verified, with a retry path instead of a silent failure.
  • Made license settings better at recognizing a remembered direct-build account so unlink and refresh actions are available when needed.
  • Updated release version handling so direct and App Store builds use the same release version source.

Fixes

  • Fixed cases where a completed checkout could still show a retryable setup error before the entitlement update arrived.
  • Fixed stale entitlement state from being treated as active access when SpeakQuick needs an online refresh.
  • Improved App Store archive defaults so release builds get an explicit marketing version and build number.
